# SpeakHands (Frontend)

SpeakHands is a prototype web application designed to improve communication between hearing individuals and the deaf-mute community through voice-to-sign language translation.

## About the Project

SpeakHands was developed as a student project with the goal of:

- Translating spoken language into sign language (prototype).
- Providing sign language learning resources.
- Eventually expanding to include accessibility-friendly services, such as a restaurant directory where staff know sign language.

## Technologies Used

- HTML5
- CSS3
